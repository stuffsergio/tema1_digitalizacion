# Tema 1.6: Hardware y software

## Resumen del vídeo: «How Computers Work: Hardware and Software»

### 1. Dos definiciones

* **Hardware**: todo lo físico, mecánico y electrónico. Circuitos, microchips, cables, altavoces, carcasa.
* **Software**: los programas que se ejecutan sobre ese hardware. Aplicaciones, juegos, páginas web, herramientas de datos.

### 2. La CPU manda sobre el hardware

La CPU es el chip maestro. Dentro tiene subcircuitos:

* Circuitos aritméticos, para operaciones matemáticas simples.
* Circuitos de entrada y salida, para hablar con el resto del sistema.

Ejecuta instrucciones binarias una tras otra. El comando «suma» activa el circuito aritmético. El comando «guarda» activa el circuito de memoria. Un programa, a este nivel, es una lista ordenada de esos comandos.

### 3. Del binario a los lenguajes de alto nivel

* **Código binario**: el software en su forma más básica, secuencias de unos y ceros. Es el único idioma que ejecuta la CPU.
* **Lenguajes de alto nivel**: escribir en binario llevaría demasiado tiempo. Se usan lenguajes cercanos al idioma humano. Un comando como «dibujar un rectángulo» se traduce en cientos o miles de comandos binarios simples.

### 4. El sistema operativo y la multitarea

* El **sistema operativo** es el programa maestro. Administra cómo el software usa el hardware. Windows, macOS y Linux son ejemplos.
* Carga programas en la memoria.
* Reparte el tiempo de la CPU y el acceso a los dispositivos de entrada y salida.
* **Multitarea**: parece que hay decenas de programas a la vez. En realidad el sistema operativo cambia de uno a otro en fracciones de segundo y comparten la misma CPU.

En una red, la salida de una computadora se convierte en la entrada de otra. En un coche o un dron, los sensores son entradas: convierten una magnitud física en binario para que la CPU decida.
